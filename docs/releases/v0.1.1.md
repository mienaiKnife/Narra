Narra v0.1.1 is a small privacy-focused update to the first release. It also picks up a few fixes
that landed after v0.1.0.

## Privacy

- **No third-party favicon lookups.** Feed and article addresses are no longer sent to Google's
  favicon service. Icons are resolved from the site's own `/favicon.ico`, and sites without one fall
  back to the existing letter avatar.
- **Honest `Referer`.** When Narra downloads a web article, it now sends that article's own origin
  as the `Referer` header instead of `https://www.google.com/`. If the origin cannot be determined,
  no `Referer` is sent at all.

Details are in [PRIVACY.md](https://github.com/mienaiKnife/Narra/blob/v0.1.1/docs/PRIVACY.md).

## Also in this release

- Feed refresh now reports which feeds failed to update instead of failing silently.
- Typographic dashes (em dash, en dash) are treated as word boundaries while reading, so word
  highlighting and navigation stay aligned.
- Settings → Licenses shows the full license texts for bundled non-code assets (OpenDyslexic 3,
  epublib-core).
- Store listing metadata for F-Droid.

## Not in this release

The Sherpa-ONNX 2.x upgrade and the related pronunciation/lexicon work are still in progress and
will ship in a later release. On-device AI voices in v0.1.1 behave as they did in v0.1.0.

## Install

1. Download `narra-v0.1.1.apk` from the assets below.
2. Allow installs from your browser or file manager when Android prompts.
3. Open Narra and choose an engine in **Settings → Voices**.

Existing v0.1.0 installations update normally; this release is signed with the same key.

On-device AI voice models are still not bundled with the APK. Download one from **Settings → Voices**
if you want to use the Sherpa-ONNX engine.

## Verify

A SHA-256 checksum is published as `narra-v0.1.1.apk.sha256`:

```bash
sha256sum -c narra-v0.1.1.apk.sha256
```

On macOS, use `shasum -a 256 -c narra-v0.1.1.apk.sha256` instead.

## Requirements

- Android 7.0 (API 24) or newer
- An ARM device (`arm64-v8a` or `armeabi-v7a`)
- Network access for feeds and for downloading on-device voice models
