Narra v0.1.0 is the first numbered release. It turns RSS feeds, EPUB files, and saved web articles
into a podcast-style listening queue using Android's built-in text-to-speech or on-device AI voices.

## Highlights

- RSS feed subscriptions with automatic article fetching
- EPUB import and reader-mode extraction for web pages
- Listening queue with background playback and system media controls
- Android's native TTS plus on-device AI voices powered by Sherpa-ONNX
- Home screen widget for playback and queue status
- OPML import and export
- File-based database backup and restore, plus optional auto-export for syncing
- No account required; content and speech synthesis stay on your device

## Requirements

- Android 7.0 (API 24) or newer
- An ARM device (`arm64-v8a` or `armeabi-v7a`)
- Network access for feeds and for downloading on-device voice models

## Install

1. Download `narra-v0.1.0.apk` from the assets below.
2. Allow installs from your browser or file manager when Android prompts.
3. Open Narra and choose an engine in **Settings → Voices**.

On-device AI voice models are not bundled with the APK. Download one from **Settings → Voices** if
you want to use the Sherpa-ONNX engine.

A SHA-256 checksum is published as `narra-v0.1.0.apk.sha256`. Verify it with:

```bash
sha256sum -c narra-v0.1.0.apk.sha256
```

On macOS, use `shasum -a 256 -c narra-v0.1.0.apk.sha256` instead.

## Before upgrading

This is the first signed release. If you previously installed a debug build, Android will reject the
update because the signing key has changed. Export a database or OPML backup first, uninstall the old
build, install this release, then restore the backup.

## Known limitations

- This is an early release; expect rough edges and please report bugs on GitHub.
- PDF import, cloud TTS providers, and cross-device sync are planned but not included yet.
- Narra does not require an account and does not operate a first-party server.
